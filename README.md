# lms soni

### setup instruction

1.clone the project 
'''
    git clone https://github.com/ankursoni8474/lms-soni.git

'''

2. Move into the directory

'''
    cd lms-soni
'''

3 install dependencies

'''
    npm i
'''

4. run the server

'''
    npm run dev
'''

5.  install tailwind css
'''
     npm install -D tailwindcss
     npx tailwindcss init
'''

6. Add file extension to tailwind config file in the content property

''' 
    "./src/**/*.{html,js,jsx,ts,tsx}"
'''
